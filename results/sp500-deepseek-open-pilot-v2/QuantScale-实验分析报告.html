01

先看结论

收益

去中心化两次运行的测试 Sharpe 都约为 0.69，平均年化收益 7.72%，在完成测试的组里最高。但收益主要来自 2024 年，2025 年一份小赚、一份亏损。

归因

这两份胜出候选生成时，收到的同伴有效结果都是零条。轨迹支持独立提案和自我修订产生了较好候选，尚不支持“同伴协作带来收益提升”。

瓶颈

71 次候选尝试，只有 16 次完成训练与验证。54 次输出截断；输出 token 的 96.3%用于推理。当前比较受到生成完成率和解析器可靠性的显著影响。

本轮值得保留的是两份可继续验证的动量组合策略，以及一套可审计的实验记录。现有证据还不足以确认稳定的拓扑排名或可部署的独立 alpha。

02

实验具体怎么设定？

这是一次固定总资源上限的开放策略代码搜索：比较相同模型和交易约束下，不同信息结构能完成多少有效研究，以及选出的策略在留出期如何表现。

训练 · 6 年2016–2021反馈研究期表现
验证 · 2 年2022–2023反馈并选择优胜者
测试 · 2 年2024–2025冻结后仅评估一次

前 8 年用于挖掘；其中后 2 年用于验证选优。测试数据和测试收益不放入研究者请求。此测试年份已用于上一轮实验，属于本轮流程留出，不是新盲测。

实验要素正式重跑的设定
股票与数据Yahoo 真实行情；当前标普成分中500只有目标年份数据，研究期495只、训练期491只有观测。不是历史逐日标普成分池。
模型与输出deepseek-flash，high推理；单次最多16,384输出token，包含推理；请求总token还受单次65,536及剩余预算限制。
重复与总组数5种拓扑 × 2次运行（标签7、17）= 10组；标签不控制服务端随机数。计划上限120次候选、1,700,000 token。
每组预算最多12次候选尝试、170,000总token；管理者、同伴上下文、格式错误和失败调用均计费。不保证实际消耗或有效候选数相同。
搜索自由度研究者自己写Python特征、信号、过滤器与仓位；不限定策略家族、窗口或参数网格。仍禁止预测模型训练、外部数据和文件访问。
仓位限制总敞口≤100%；单股绝对权重≤2%；净敞口绝对值≤1%。模型需返回每只当期股票的有限权重，未持有项为0。
执行与费用收盘t决策→下个有效开盘成交→再下个开盘结算；交易名义量按权重绝对变化之和计算，费率5bp，空头借券年化30bp。
选优与测试每组按验证扣费后Sharpe选1份，平分按策略SHA升序；10组研究尝试全部结束后统一登记，7份有效提交各测试1次，3组失败不补跑。
执行限制每次策略调用限时10秒，每段回测限时180秒；隔离进程，未实施严格RAM上限。各数据划分从空仓开始，可读取之前历史预热。

一个候选如何变成最终测试策略？

  1. 提出候选假设 + 完整Python模块
  2. 运行研究回测代码检查 → 训练 → 验证
  3. 反馈并继续依据拓扑提供自身 / 同伴 / 分工信息
  4. 选出并冻结每组取验证Sharpe最高的1份
  5. 统一测试全部组结束后，最后2年各评估1次

研究者提交错误或回测失败：扣一次候选并继续。管理者输出不满足协议：当前实现直接终止该组，这是本轮需要披露的惩罚不对称。反馈没有形成有效结果时，同伴快照中不会凭空出现可共享的策略。

五种拓扑：研究者之间如何连接？

五组使用同一类研究者、数据接口和回测器，区别在于下一次提案能读取哪些信息。图中的 W 是生成策略代码的研究者，M 是负责分工的管理者；评估器与数据属于公共实验设施，不计入 Agent 数。

管理者 → 研究者：研究分工研究者 ↔ 研究者：同伴有效结果虚线：历史结果 / 下一轮反馈
SINGLE

单 Agent

1 名研究者

每次提案读取自己最近 3 条候选结果，包括错误记录。用同一份训练与验证反馈进行下一次尝试。

INDEPENDENT

独立并行

4 名研究者，无管理者

各自只看自身历史。12 次候选上限按每人最多 3 次分配，共享一组 token 预算；实际可能提前耗尽。

CENTRALIZED

中心化

4 名研究者 + 1 名管理者

每轮开始时，管理者读取各 W 截至上一轮的最近有效结果并给每人分工。W 读取分工和自身历史，不直接读取其他 W 的结果。

DECENTRALIZED

去中心化

4 名研究者，无管理者

每名 W 可读取其他 W 在上一轮结束前最近一次有效结果，里面包含假设、代码和训练/验证指标。软件只负责整理快照。

HYBRID

混合

4 名研究者 + 1 名管理者

同时保留管理者分工和同伴共享：每名 W 读取本轮分工、自身历史，以及上轮其他 W 的最近有效结果。

图示需要结合三条实际执行规则理解。
  • 所有 W 都只收到自身最近 3 条候选结果；图中未在每个 W 下重复画本地历史。
  • 同伴与管理者读取的是“截至上一轮的快照”。本轮先调用的 W 即使已产生新结果，也不会立即分享给同轮其他 W；没有有效结果时，相应上下文为空。
  • W 在每组内按编号顺序调用，不是四路同时执行；实验并发 4 路指不同实验组。每组最后统一按验证 Sharpe 选 1 份策略，不把多名 W 的策略自动组合成投资组合。

图源：正式实验冻结的 research.py 信息流。实线和虚线表示逻辑信息关系，不代表同一时刻通信或额外模型调用。管理者和同伴内容均计入该组统一 token 预算。

七份策略究竟怎么做？

下文以实际代码为准。Rank 是当期有效股票的百分位排序；Z 是横截面标准化。“月度 / 周度”表示特征截止到月末或周五，并不等于只在那天交易：股票池、排名和目标权重仍可能逐日变化，回测每天按目标权重再平衡。

单 Agent · 7 月度信号：双周期动量、近月反转、低波动测试 Sharpe -0.33 · 年化 -3.25%
0.55×Rank(6个月动量) + 0.45×Rank(12个月动量) − 0.20×Rank(近21日收益) − 0.25×Rank(126日波动率)

用上个月末数据，动量跳过最近约21个交易日；筛选流动性，每边最多50只，等权，目标总敞口约0.98。

代码核读：短历史时12个月项退回6个月项；信号输入自行做前向填充。月度更新信号不等于整月不交易，回测每天仍按目标权重再平衡。测试亏损在取消交易费的静态情景下仍存在。

import numpy as np
import pandas as pd

def generate_weights(history, universe):
    u = pd.Index(universe)
    z = pd.Series(0.0, index=u, dtype=float)
    if len(u) == 0:
        return z
    ac = history.get('adjusted_close')
    cl = history.get('close')
    vo = history.get('volume')
    el = history.get('eligible')
    if ac is None or cl is None or vo is None:
        return z
    ac = ac.reindex(columns=u)
    cl = cl.reindex(columns=u)
    vo = vo.reindex(columns=u)
    idx = ac.index
    if len(idx) < 130:
        return z
    last = idx[-1]
    per = idx.to_period('M')
    pm = per < last.to_period('M')
    if pm.any():
        asof = idx[pm][-1]
    else:
        asof = last
    ac = ac.loc[:asof]
    cl = cl.loc[:asof]
    vo = vo.loc[:asof]
    if len(ac) > 320:
        ac = ac.iloc[-320:]
        cl = cl.iloc[-320:]
        vo = vo.iloc[-320:]
    if len(ac) < 130:
        return z
    ac = ac.ffill()
    cl = cl.ffill()
    ret = ac.pct_change(fill_method=None)
    px = ac.iloc[-1]
    dv = (cl * vo).rolling(20, min_periods=5).median().iloc[-1]
    good = px.notna() & (px > 2.0) & dv.notna() & (dv > 5e5)
    if el is not None:
        e = el.reindex(columns=u)
        if len(e) > 0:
            e = e.loc[:asof]
            if len(e) > 0:
                good = good & e.iloc[-1].fillna(False).astype(bool)
    n = len(ac)
    p0 = ac.iloc[-1]
    p1 = ac.iloc[-22] if n >= 22 else ac.iloc[0]
    p6 = ac.iloc[-127] if n >= 127 else ac.iloc[0]
    if n >= 252:
        p12 = ac.iloc[-252]
    else:
        p12 = p6
    mom6 = p1 / p6 - 1.0
    mom12 = p1 / p12 - 1.0
    rev = p0 / p1 - 1.0
    vola = ret.iloc[-126:].std()
    good = good & np.isfinite(mom6) & np.isfinite(mom12) & np.isfinite(vola) & np.isfinite(rev)
    good = good & (vola > 0.0) & (vola < 0.15)
    cand = u[good.to_numpy()]
    if len(cand) < 20:
        return z
    m6 = mom6[cand].rank(pct=True)
    m12 = mom12[cand].rank(pct=True)
    rv = rev[cand].rank(pct=True)
    lv = vola[cand].rank(pct=True)
    score = 0.55 * m6 + 0.45 * m12 - 0.20 * rv - 0.25 * lv
    ns = int(min(50, max(10, len(cand) // 10)))
    ns = min(ns, len(cand) // 2)
    if ns < 1:
        return z
    order = score.sort_values(ascending=False)
    longs = order.index[:ns]
    shorts = order.index[-ns:]
    q = 0.49 / float(ns)
    if q > 0.02:
        q = 0.02
    w = z.copy()
    w.loc[longs] = q
    w.loc[shorts] = -q
    return w.fillna(0.0).astype(float)

    out = pd.Series(0.0, index=u, dtype=float)
    if len(u) == 0:
        return out
    close = _frame(history, ['adjusted_close', 'close'])
    if close is None or close.empty:
        return out
    close = close.copy()
    cols = [c for c in u if c in close.columns]
    if len(cols) < 4:
        return out
    close = close[cols].astype(float).replace([np.inf, -np.inf], np.nan)
    dates = close.index
    if len(dates) < 60:
        return out
    max_date = dates[-1]
    first = pd.Timestamp(year=max_date.year, month=max_date.month, day=1)
    prev_end = first - pd.Timedelta(days=1)
    cand = dates[dates <= prev_end]
    if len(cand) > 0:
        ref_date = cand[-1]
    else:
        ref_date = max_date
    px = close.loc[:ref_date]
    if len(px) < 60:
        px = close
        ref_date = max_date
    p = px.replace([np.inf, -np.inf], np.nan)
    nrows = len(p)
    mom_lb = 126 if nrows > 126 else 60
    skip = 5
    mom = p.shift(skip) / p.shift(mom_lb) - 1.0
    ret5 = p / p.shift(skip) - 1.0
    rets = p / p.shift(1) - 1.0
    vol = rets.rolling(window=60, min_periods=30).std()
    ma = p.rolling(window=100, min_periods=50).mean()
    trend = p / ma - 1.0
    last_mom = mom.iloc[-1]
    last_ret5 = ret5.iloc[-1]
    last_vol = vol.iloc[-1]
    last_trend = trend.iloc[-1]
    last_price = p.iloc[-1]
    valid = pd.Series(True, index=cols, dtype=bool)
    valid = valid & last_price.notna() & (last_price > 0)
    valid = valid & last_mom.notna() & np.isfinite(last_mom)
    valid = valid & last_ret5.notna() & np.isfinite(last_ret5)
    valid = valid & last_vol.notna() & np.isfinite(last_vol) & (last_vol > 0)
    valid = valid & last_trend.notna() & np.isfinite(last_trend)
    elig = history.get('eligible', None)
    if isinstance(elig, pd.DataFrame):
        e = elig.reindex(index=close.index, columns=cols).ffill(limit=5)
        if len(e) > 0:
            ecur = e.iloc[-1].fillna(True).astype(bool)
            valid = valid & ecur.reindex(cols).fillna(True)
            esub = e.loc[:ref_date]
            if len(esub) > 0:
                eref = esub.iloc[-1].fillna(True).astype(bool)
                valid = valid & eref.reindex(cols).fillna(True)
    volf = history.get('volume', None)
    if isinstance(volf, pd.DataFrame):
        vv = volf.reindex(index=close.index, columns=cols).loc[:ref_date]
        raw_close = _frame(history, ['close', 'adjusted_close'])
        if raw_close is not None:
            rc = raw_close.reindex(index=close.index, columns=cols).loc[:ref_date]
        else:
            rc = p
        adv = (rc * vv).rolling(20, min_periods=5).mean().iloc[-1]
        valid = valid & adv.notna() & (adv > 1e5)
    sel = list(valid[valid].index)
    if len(sel) < 4:
        return out
    m = last_mom.reindex(sel).astype(float)
    r = last_ret5.reindex(sel).astype(float)
    v = last_vol.reindex(sel).astype(float)
    t = last_trend.reindex(sel).astype(float)
    v_floor = v.quantile(0.05) if len(v) >= 20 else v.min()
    if (not np.isfinite(v_floor)) or v_floor <= 0:
        v_floor = 1e-6
    ram = m / v.clip(lower=v_floor)
    rank_ram = ram.rank(pct=True, method='average') - 0.5
    rank_rev = (-r).rank(pct=True, method='average') - 0.5
    rank_trend = t.rank(pct=True, method='average') - 0.5
    score = 0.65 * rank_ram + 0.25 * rank_rev + 0.10 * rank_trend
    score = score.replace([np.inf, -np.inf], np.nan).dropna()
    if len(score) < 4:
        return out
    n_side = min(50, len(score) // 2)
    if n_side < 1:
        return out
    sorted_scores = score.sort_values(ascending=False)
    top = list(sorted_scores.index[:n_side])
    bottom = list(sorted_scores.index[-n_side:])
    w = min(0.02, 0.499 / float(n_side))
    if (not np.isfinite(w)) or w <= 0:
        return out
    out.loc[top] = w
    out.loc[bottom] = -w
    overlap = set(top).intersection(set(bottom))
    if len(overlap) > 0:
        for c in overlap:
            out.loc[c] = 0.0
    out = out.replace([np.inf, -np.inf], 0.0).fillna(0.0)
    gross = float(np.abs(out.values).sum())
    if gross > 1.0:
        out = out * (0.999 / gross)
    return out
