先看：完整提交、有效实验和费用分别怎么变了？

交付

完整代码提交率从 23.94% 变为 96.74%；完成训练与验证的候选从 16 个变为 73 个。最终冻结提交为 7/10 → 9/10，这与单次代码提交率是两个指标。

token

已确认总量 1,215,706 → 1,318,114（变化 +8.4%）。每个有效候选的已确认token为 75982 → 18056。本轮有 1 个请求无用量回执，不能把已确认量当成完整账单。

解读

更多可运行策略意味着更高研究覆盖量，不保证测试盈利。代码生成、运行正确性、组级提交和最终收益在下文分别统计；同一预算上限不代表实际总消耗相等。

每组仅两次，实际token和有效候选数不同，管理者还增加一个不同推理设置的角色；最终策略的经济方向也不同。因此，结构差异、预算分配、策略风格和随机性混在一起。这里最有价值的是提出后续消融问题，而不是给管理者或同伴信息“定价”。

逐个结构，更具体地理解

单Agent：唯一完成的运行有明显自我修订，但测试失败；另一次因网络中断。它说明独立迭代也能提高验证成绩，不能把混合组的验证改善全部归功于通信；也没有足够完整重复来判断单Agent整体稳定性。

独立并行：20个有效候选、每个约1.34万token，产出便宜且多，但最终两份测试都亏损。当前问题不只是“探索不够”，而是独立生成与验证选优没有稳定找到泛化方向。尚无证据证明所有损失来自重复搜索。

中心化：两次测试Sharpe为−0.61和1.10，均值0.25掩盖了很大的分歧。管理者有组织修订方向的轨迹，但一份选到反转方向，另一份选到含高Beta与状态切换的动量方向；不能把均值看成稳定的中心化收益。

去中心化：一次赢家来自首轮，无同伴信息；另一次收到一条同伴有效结果，却只有极小验证改善，最终测试−1.44。当前更准确的说法是“共享没有在这两次运行中稳定创造超越首轮的候选”，而不是“大家互相抄袭导致失败”。

混合：两次都在后续轮次产生赢家，均收到管理者分工与三条同伴有效结果，两份测试均盈利。它是本轮最值得继续验证的机制线索；不过，自身反馈、同伴反馈、管理者分工同时存在，还无法分离各自贡献。

来源：V3逐次评估和信息流配置。Sharpe均值的差值不是收益率差值，也不是组合策略Sharpe。比较没有控制底层金融因子，不是严格随机的2×2因果试验。

混合：出现了两次可追踪的方向修订

混合·7从首轮最佳−0.577提升到后续0.069；赢家由W2从快速残差反转转向月末残差动量。混合·17从−0.456提升到0.040；W2先前因仓位限制没有有效结果，随后提出月度状态切换的高低波动率多空策略。两次赢家均在第1轮，收到三条同伴的亏损回测和管理者分工。

这支持“系统能够依据已有失败经济证据提出不同方向”的观察，却不证明同伴消息是必要原因。混合·7同时有自己的负反馈；混合·17也有自己的仓位错误反馈。没有相同任务下的共享关闭对照，无法排除自行修订或管理者单独分工也能产生同一方案。

去中心化：信息共享存在，但边际搜索改进很弱

去中心化·17的后续最佳0.139没有超过首轮0.216，最后保留首轮独立提案。去中心化·7仅从−0.0155变为−0.0119，改进约0.0036。不能据此证明共享有害，但这两次没有显示稳定的增量发现能力。

验证改善不是协作独有，也不是测试盈利的保证

单Agent·7从首轮−0.245提高到0.432，幅度约0.678，却在测试期得到−0.837。中心化·7和独立并行·7也改善了验证最佳值，但最终测试为负。因此，仅用“后续验证改善幅度”衡量拓扑，会混淆自我反馈、更多选优机会和真正泛化能力。

当前信息结构还有两项具体限制

  • 共享的是完成回测的候选，包括亏损策略；执行错误不会共享。管理者和同伴只拿各W最近一次有效结果，无法直接看见仓位违规、超时、禁用函数等失败细节。混合·17的W2首轮仓位违规，管理者下一轮只知道没有有效结果；W2自己才持有具体错误。

def _capped_inv_vol(inv, target, cap):

    inv = np.asarray(inv, dtype=float)

    if inv.sum() <= 0:
        w = np.full(n, target / n, dtype=float)
        return np.minimum(w, cap)
    w = np.zeros(n, dtype=float)

        idx = np.flatnonzero(active)
        if idx.size == 0:
            break

            remaining = 0.0
            break

            remaining = 0.0
